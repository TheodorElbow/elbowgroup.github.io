# Elbow Group studio website

A responsive, interactive one-page website for Elbow Group, built with React, TypeScript, CSS, and vinext.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. Use `npm run build` to create a production build.

## Included interactions

- Project carousel with arrows, keyboard navigation, pagination, and mobile swipe
- Responsive desktop, tablet, and mobile layouts
- Motion with reduced-motion accessibility support
- Direct Google Play links on every project card
- Official app icons downloaded from Google Play
