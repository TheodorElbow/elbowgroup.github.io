# Elbow Group — GitHub Pages package

This folder is ready to publish on GitHub Pages. It contains only static files and uses relative asset paths, so it works both at `username.github.io` and `username.github.io/repository-name/`.

## Publish

1. Create a repository on GitHub.
2. Upload the contents of this folder to the repository root. Do not upload the ZIP file itself.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then click **Save**.

GitHub will display the public address after deployment finishes.
